# DatPhongHoc – Ứng dụng Đặt Phòng Học

## 1. Giới thiệu

DatPhongHoc là ứng dụng mobile hỗ trợ người dùng tìm kiếm và đặt phòng học.

Ứng dụng được phát triển bằng React Native và Expo, cung cấp các chức năng tìm kiếm phòng, lọc phòng, xem chi tiết phòng, đặt phòng, quản lý lịch đặt và lưu dữ liệu đặt phòng cục bộ.

---

## 2. Chức năng chính

- Xem danh sách phòng học
- Tìm kiếm phòng theo tên
- Lọc phòng theo trạng thái
- Lọc theo sức chứa
- Xem chi tiết phòng
- Chọn ngày đặt phòng
- Chọn khung giờ
- Kiểm tra trùng lịch
- Tạo lịch đặt phòng
- Xem lịch đã đặt
- Hủy lịch đặt
- Lưu dữ liệu bằng AsyncStorage

---

## 3. Công nghệ sử dụng

- React Native
- Expo SDK 57
- TypeScript
- Expo Router
- Zustand
- AsyncStorage
- EAS Build
